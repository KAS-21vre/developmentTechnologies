# Журнал ADR

Записи ведутся в MADR, имеют постоянный четырёхзначный номер, статус, дату, контекст, движущие факторы, минимум две альтернативы, решение, последствия и условие пересмотра. Принятые записи не переписываются: новая запись заменяет старую.

| ADR | Решение | Статус |
|---|---|---|
| [0001](0001-record-architecture-decisions.md) | Вести MADR | Принято |
| [0002](0002-backend-language.md) | Серверный стек | Предложено, сверить с кафедрой |
| [0003](0003-architecture-style.md) | Модульный монолит + гексагональные границы | Принято |
| [0004](0004-persistence.md) | PostgreSQL | Предложено к подтверждению |
| [0005](0005-authentication.md) | Серверная аутентификация и авторизация | Принято концептуально |

- [ADR-0006 — Раздача веб-клиента](0006-static-client-hosting.md) — отдельный сервер статических файлов (предложено к подтверждению).
