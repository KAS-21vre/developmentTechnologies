# REST API — ресурсы SkillSwap

**Версия:** `/v1` · **Статус:** проектный перечень операций для OpenAPI в ЛР 4Б, не реализованный API.

## Общие правила
JSON; UUID; даты ISO 8601 с часовым поясом; списки имеют `page`/`pageSize` (максимум 100). Защищённые операции требуют входа. Ошибка: `code`, `message`, `details`. Конфликт состояния — `409`.

## Коды
`200` успешно; `201` создано; `400` некорректный запрос; `401` не аутентифицирован; `403` нет прав; `404` не найдено; `409` конфликт состояния; `422` нарушено правило предметной области.

## Сквозной пример FR-23
Требование двух подтверждений → агрегат `Exchange` и событие `ExchangeCompleted` → модуль Exchange и транзакционная БД → `POST /v1/exchanges/{id}/confirm-completion` → первый запрос не завершает обмен, второй от другого участника переводит его в COMPLETED.
