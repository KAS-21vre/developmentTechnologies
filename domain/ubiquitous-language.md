# Единый язык SkillSwap

| Термин | Определение | Имя в коде |
|---|---|---|
| Участник | Зарегистрированный пользователь платформы | `User` |
| Профиль | Публичные данные и интересы участника | `UserProfile` |
| Навык | Умение из общего каталога | `Skill` |
| Могу обучать | Навык, которым участник готов делиться | `TeachingSkill` |
| Хочу освоить | Навык, который участник хочет изучить | `LearningSkill` |
| Публикация | Запись в каталоге типа предложение или запрос | `Listing` |
| Предложение об обучении | Публикация OFFER | `ListingType.OFFER` |
| Запрос на обучение | Публикация REQUEST | `ListingType.REQUEST` |
| Предложение обмена | Инициатива двух участников договориться | `ExchangeProposal` |
| Обмен | Согласованное взаимодействие двух участников | `Exchange` |
| Условия обмена | Согласованные навыки и правила взаимодействия | `ExchangeTerms` |
| Занятие | Запланированная встреча/сессия | `Session` |
| Подтверждение проведения | Отметка участника о проведённом занятии | `CompletionConfirmation` |
| Завершённый обмен | Обмен с двумя подтверждениями | `ExchangeStatus.COMPLETED` |
| Отзыв | Оценка и комментарий после обмена | `Review` |
| Рейтинг | Вычисляемое среднее последних 50 отзывов | `Rating` |
| Жалоба | Обращение о нарушении правил | `Report` |
| Модератор | Пользователь с правом рассматривать жалобы | `Moderator` |

## Не смешивать
- Публикация — объявление в каталоге; предложение обмена — конкретное взаимодействие двух участников.
- Согласовано время ≠ занятие проведено ≠ обмен завершён.
- Участник может обучать в одном обмене и учиться в другом.
- Отзыв — запись; рейтинг — вычисляемый показатель.
- Отклонение и отмена не означают успешное завершение.

## Проверка трёх совпадений
`Listing`: `ListingPublished` в event storming, агрегат `Listing`, требования `FR-20/21`. `Exchange`: `ExchangeProposed/ExchangeCompleted`, агрегат `Exchange`, `FR-22/23`. `Review`: `ReviewPublished`, агрегат `Review`, `FR-24`.
